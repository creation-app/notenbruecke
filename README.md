# Die Notenbrücke

Ein Notenlern-Spiel für Klavierschüler: Noten lesen, schreiben und am echten Klavier spielen. Das Mikrofon erkennt den gespielten Ton.

- Test-Fassung (alles frei): `index.html`
- Kauf-Fassung (Schranke nach den ersten Leveln, gleiches Spiel, gleiche Spielstände): `shop/index.html`
- Quelltext und Tests: Ordner `quelltext/`

Spielstände bleiben auf dem Gerät des Kindes.
